Prepare your files

Choose a baseline and revision in .xlsx or comma-separated UTF-8 CSV format. Include description, unit, quantity and unit rate. Optional fields include reference, section and amount. Keep references with leading zeros as text. Use a single currency and consistent units. Recalculate Excel formulas before saving.

Convert .xls, .xlsb and .xlsm to a clean .xlsx or CSV copy. Unhide rows and sheets, unmerge cells and remove password protection on your copy. Split out covers and summary-only sheets. Each version can contain up to 25,000 priced lines.

Investigate a difference

Select a row for quantities, rates, source locations and the match explanation. A supplied amount drives financial totals even when arithmetic differs. Review rows remain unpaired. Check the original scope, correct references in a copy if appropriate, and import again. Both exports include all rows regardless of the active filter.

Report a problem

Open a QuantForge Labs support issue. Issues are public. Include the application version, file type, error text and reproduction steps using synthetic values. Keep project names, financial details and client files private.
